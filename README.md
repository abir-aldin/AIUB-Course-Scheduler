# AIUB Course Scheduler

![AIUB Course Scheduler Banner](banner.png)

An automated web-based course scheduling system designed for AIUB students to generate optimized and clash-free class routines.

## Overview

AIUB Course Scheduler helps students create suitable class schedules by analyzing course offerings, section availability, and scheduling preferences.

The system reduces manual effort by automatically generating possible schedules while considering time conflicts and user constraints.

## Features

- 📂 Upload course offering Excel files
- 🔍 Search and select courses easily
- ⚡ Automatic section selection
- ✅ Clash-free schedule generation
- 👥 Student count filtering
- ⚙️ Schedule preference configuration
- 🔒 Fixed/constant course support
- 📊 Schedule ranking based on minimum class gaps

## Technologies Used

- HTML
- CSS
- JavaScript
- SheetJS (Excel file processing)

## How It Works

1. Upload the AIUB course offering Excel file
2. Configure scheduling preferences
3. Select required courses
4. Generate possible schedules
5. Choose the most suitable routine

## Project Purpose

This project was developed to simplify the course planning process for AIUB students by providing an automated scheduling solution.
